Core Architecture • 03

Local-First Engine with User Profile Isolation

Engineered from ground up with client-side cryptography and isolated browser data boundaries.

🔐 Cryptographic Client Sessions
- OWASP PBKDF2 password derivation (600,000 iterations, Web Crypto API)
- Zero plaintext password persistence
- Per-user namespace isolation (`prarush_usr_${userId}_*`)
- Sliding 30-day inactivity expiration refreshed on usage
🗄️ Dual-Store Persistence Engine
- LocalStorage: Workspaces, Kanban boards, markdown notes, preferences
- IndexedDB (`prarush_files_db`): Authentic binary files (PDFs, images, archives) scoped by local user profile ID
- Real browser origin storage quota monitoring

Binary Storage & Streams • 06

Persistent Files & Native GZIP Streams

Authentic binary preservation in IndexedDB with zero fake simulated placeholders.

🗃️ Persistent IndexedDB Storage
- Real byte storage up to local browser origin quotas
- Uploaded files persist across page reloads and browser restarts
- Scoped by user profile ID to prevent local cross-account leakage
- Sample metadata records explicitly labeled and prevented from fake downloads
🗜️ Native Browser GZIP Engine
- Built on native browser `CompressionStream('gzip')`
- Calculates genuine byte reduction and compression ratios
- Exports real `.gz` archives from authentic binary bytes
- Text parsing for Markdown, JSON, CSV, and code files
