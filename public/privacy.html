LOCAL-FIRST PRIVACY & DATA TRANSPARENCY NOTICE

Privacy Policy & Data Notice

Last Updated: October 2026 | Current Status: Local-First Developer Prototype

1. Architecture & Data Ownership

Prarush is currently engineered as a local-first browser application. Workspaces, Kanban sprint tasks, markdown notes, calendar events, and document records are stored locally in your browser's persistent storage (LocalStorage and client memory). We do not collect, monetize, or train foundation models on your private notes or project records.

2. Authentication & API Keys

  • Client-Side Accounts: Account registration and passwords use client-side salted SHA-256 cryptographic hashing (Web Crypto API) and random session tokens. Sessions expire after 30 days of inactivity. Cross-device cloud sync is not currently active.
  • Bring-Your-Own-Key (BYOK): When you configure API keys (OpenAI, Google Gemini, Anthropic, OpenRouter), these keys are stored exclusively in your browser (with optional session-only storage). Inference requests connect directly from your browser to the chosen provider's HTTPS endpoint without routing through an intermediate proxy or server.

3. Third-Party AI Providers

When you initiate live model queries using your personal API keys:

  • Anthropic: Direct connection via official Messages API. Subject to Anthropic Privacy Policy.
  • OpenAI: Direct connection via official Chat Completions API. Subject to OpenAI Privacy Policy.
  • Google DeepMind: Direct connection via Generative Language API using header-based authentication. Subject to Google API Services User Data Policy.
  • OpenRouter: Direct connection for open-weights models. Subject to OpenRouter Privacy Policy.

4. Data Portability & Erasure

Prarush provides built-in tools for user data control:

  • JSON Data Export: You can export your stored workspaces, tasks, notes, documents, and preferences as a machine-readable JSON file at any time from the Profile drawer.
  • Origin-Safe Storage Purge: 1-click storage reset allows clearing all prarush_* browser records from your device without affecting other websites' cookies.
  • Local Modification: All notes, task records, and user profiles can be directly edited or deleted in real time.

5. Prototype Status & Future Cloud Services

This privacy notice applies to the current client-side prototype. Before launching multi-user cloud synchronization, server databases, or payment processing, our terms and privacy documentation will be updated to describe backend storage, encryption at rest, and third-party subprocessors.

6. Contact & Questions

For questions or feedback regarding privacy or data handling, reach out at: privacy@prarush.local
